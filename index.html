1. 분석 배경 및 목표

음원 사이트의 차트는 순위만 보여줄 뿐, 인기 곡들이 일반적인 곡들과 오디오 수치상 어떤 구체적인 차이를 가지는지 설명하지 않습니다. 본 프로젝트는 Spotify API에서 제공하는 Audio Features 데이터를 활용하여 대중이 선호하는 음악의 정량적 특징을 입증하고자 진행되었습니다.

2. 데이터 수집 (Data Collection)

Spotify for Developers API를 통해 2023년 발매 트랙 1,000건의 데이터를 수집했습니다. API의 호출 제한(Limit)을 고려하여 오프셋을 이용한 중첩 루프 로직을 구현했으며, 각 트랙의 아티스트 정보와 오디오 특성 데이터를 리스트로 파싱하여 DataFrame으로 병합했습니다.

# API 호출 및 트랙 메타데이터 분할 수집
artist_name, track_name, track_id, track_popularity = [], [], [], []

for i in range(0, 1000, 50):
    track_results = sp.search(q='year:2023', type='track', limit=50, offset=i)
    for idx, t in enumerate(track_results['tracks']['items']):
        artist_name.append(t['artists'][0]['name'])
        track_name.append(t['name'])
        track_id.append(t['id'])
        track_popularity.append(t['popularity'])

3. 데이터 전처리 (Preprocessing)

Pandas를 활용해 분석에 불필요한 메타데이터 URL 열을 제거하고, 통계 분석 과정에서 발생할 수 있는 타입 오류를 방지하고자 각 열의 목적에 맞게 데이터 타입(String, Numeric, Category)을 명시적으로 변환했습니다.

# 불필요한 분석 식별자 열 제거
cols_to_drop2 = ['key', 'mode', 'type', 'uri', 'track_href', 'analysis_url']
tf_df = tf_df.drop(columns=cols_to_drop2)

# 연산을 위한 데이터 타입 최적화
track_df['artist_name'] = track_df['artist_name'].astype("string")
tf_df['duration_ms'] = pd.to_numeric(tf_df['duration_ms'])
tf_df['instrumentalness'] = pd.to_numeric(tf_df['instrumentalness'])
tf_df['time_signature'] = tf_df['time_signature'].astype("category")

4. 비교 분석 및 시각화

데이터의 직관적인 해석을 위해 7개의 핵심 오디오 지표를 선별했습니다. 각 지표는 0.0에서 1.0 사이의 수치로 산출됩니다.

지표 (Feature) 설명
Danceability 리듬과 비트가 강하고 활발하여 춤추기에 적합한 정도
Energy 곡의 빠르기, 화려함, 노이즈 등 사운드 에너지의 정도
Valence 곡이 전달하는 긍정적인 감정(밝음, 희망, 명료함)의 정도
Acousticness 전자음이 아닌 어쿠스틱 사운드 요소가 포함된 비중
Liveness 라이브 연주나 공연의 현장감이 포함된 정도
Instrumentalness 보컬이나 가사가 포함되지 않은 기계적/기악곡의 정도
Speechiness 노래 안에서 말하는 소리(가사, 랩 등)가 차지하는 비중

Popularity 상위 100개 곡을 필터링한 뒤, 위 7개 지표를 기준으로 전체 1,000개 트랙의 평균값과 Top 100 평균값을 산출하여 Plotly의 Scatterpolar 레이더 차트로 비교했습니다.

5. 최종 분석 결과 및 시사점

주요 분석 요약

인기 트랙(Top 100)은 전체 평균 대비 Danceability, Valence, Acousticness 수치가 높게 나타났습니다. 반면 Instrumentalness와 Liveness는 현저히 낮은 수치를 기록했습니다.

이는 대중이 리듬감이 있고 밝은 분위기의 곡을 선호하며, 라이브 현장감보다는 스튜디오에서 정밀하게 다듬어진 보컬 중심의 음원을 주로 소비한다는 점을 시사합니다. 특히 인기 트랙에서 어쿠스틱 사운드의 비중이 상대적으로 높다는 점은 디지털 사운드 중심의 음원 시장 내에서도 자연스러운 어쿠스틱 요소를 포함한 곡들의 대중성이 높음을 보여줍니다.
